# ShipLine Management System

This project is a C# simulation of a ship line management system, focusing on cargo transportation between multiple ports.

## About

The system simulates the movement and handling of cargo across different ports, including scheduling, loading, and unloading operations.

## Features

- Cargo management system
- Multiple port handling
- Ship routing between ports
- Loading and unloading simulation
- Basic scheduling logic for shipments

## Purpose

This project was built as a learning exercise to practice system design and simulation logic in C#.
